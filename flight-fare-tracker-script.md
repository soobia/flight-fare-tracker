# Flight Fare Tracker

Check round-trip flight fares from YOUR_ORIGIN to YOUR_DESTINATION 
for YOUR_OUTBOUND_DATES departure and YOUR_RETURN_DATES return.

## Trip details
- Origin: YOUR_ORIGIN airport code (e.g. JFK)
- Destination: YOUR_DESTINATION airport code (e.g. KHI)
- Outbound: YOUR_OUTBOUND_DATE_RANGE (e.g. May 12-18)
- Return: YOUR_RETURN_DATE_RANGE (e.g. June 12-18)
- Stops: 1 stop only (no nonstop, no 2+ stops)
- Travelers: 1 adult
- Cabin: Economy

## Steps

1. Search the web for current round-trip fares on this route for the 
   date range above. Use queries like:
   "[ORIGIN] to [DESTINATION] round trip [MONTH YEAR] one stop cheapest fare"
   Check aggregator sites: Google Flights, Kayak, Skyscanner, Momondo, Expedia.

2. Look specifically for fares from major airlines on this route.
   Replace this list with the main carriers for your route:
   - Etihad Airways
   - Turkish Airlines
   - Qatar Airways
   - Emirates
   - National carrier if applicable

3. Collect the best fares -- note the airline, layover city, approximate 
   price, and where the fare was found.

4. Report a clean summary with:
   - The cheapest fare found and which airline/site
   - Top 3-5 options with prices and layover cities
   - Any notable trends (prices rising, best days to fly)
   - Direct links to booking pages where possible

Keep the output concise and scannable.
